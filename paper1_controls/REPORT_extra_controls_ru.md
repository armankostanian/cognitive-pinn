## 1. Главное в пяти строках

1. **Λ по темам не нужна для качества.** Общая Λ (один скаляр) даёт тот же AUC (test 0,6553 против 0,6553); трудность темы при этом несёт δ (ρ = 0,945), а не Λ.
2. **Корреляция Λ̂ с трудностью порождается расписанием и структурой модели.** На реальном расписании Junyi Λ̂ коррелирует с трудностью (ρ ≈ 0,7) даже если истинная Λ одинакова у всех тем или не связана с трудностью. Диапазон Λ̂ при этом почти совпадает с реальным.
3. **Это объясняет большую часть, но не всё:** реальное ρ = 0,83, в симуляции 0,69–0,72. Нельзя писать «целиком артефакт».
4. **Протокол контролей специфичен только при наблюдаемом забывании.** При параметрах из задания положительный контроль нечувствителен (не годится как доказательство); при подобранных параметрах (Э1б) перемешивание убирает сигнал Λ (частная ρ 0,40 → 0,03), а BKT истинную Λ не воспроизводит.
5. **Слабые места, о которых лучше сказать самим** (раздел 7): δ и β заданы на уровне темы, ранг 25, один фолд, подгонка параметров в Э1б.

## 3. Э3 — абляция «Λ против параметров заданий»

| (5 сидов, среднее ± SD) | базовая модель | общая Λ |
|---|---|---|
| val AUC | 0,6457 ± 0,0003 | 0,6457 ± 0,0003 |
| test AUC | 0,6553 ± 0,0002 | 0,6553 ± 0,0002 |
| ρ(Λ, difficulty) | 0,834 ± 0,006; интервалы по темам ≈ [0,63; 0,93] | Λ = 0,034 (одна на все темы) |
| ρ(δ, difficulty) | 0,945 ± 0,003; интервалы ≈ [0,86; 0,97] | 0,945 ± 0,004; [0,86; 0,97] |
| ρ(β, difficulty) | −0,916 ± 0,006 | −0,920 ± 0,004 |

**Значения Λ (на шаг сетки взаимодействий), базовая модель:** мин 0,031; медиана 0,039; макс 0,085. Разброс по сидам: медиана SD по темам 0,0002; попарная ρ между сидами ≥ 0,995. Для рецензента: Λ воспроизводима, но её вариация между темами мала (в 2,7 раза).

**Что показывает.** При общей Λ AUC не меняется, трудность темы целиком в δ (ρ = 0,945 и до, и после). Значит, Λ по темам не нужна для качества, а её корреляция с трудностью (0,83) вторична.

**Нюанс против текста задания.** Ожидалось, что при общей Λ трудность «уйдёт» в δ. Фактически δ несёт трудность и в базовой модели (0,945 уже там); Λ следует за трудностью, но не несёт её. Формулировать так: «δ уже объясняет трудность; Λ добавляет к этому только коррелированный остаток».

**Шаг 3 (свободный сдвиг c_j) не выполнен как самостоятельный расчёт.** δ и β в модели индексируются темой (`n_items = K`, `item_idx = skill`), поэтому c_j тождественен δ_j; ρ(c, difficulty) = ρ(δ, difficulty) = 0,945. Это надо сказать явно (раздел 7, п. 1).

## 4. Э1 — положительный контроль

Синтетическая когорта: K = 39, N = 5000, сетка взаимодействий, Λ_true лог-равномерно на [0,01; 0,2], блоки практики (амплитуды 1 и 2,5), паузы ≥ 20 шагов с замерами в начале, середине, конце. C1 — перемешивание внутри ученика, C2 — BKT.

### 4.1 Как в задании (A: диагональ ~4, внедиагональ 0,5, β ∈ [1; 1,8])

| | значение |
|---|---|
| ρ(Λ̂, Λ_true) | 0,11 ± 0,19 |
| после перемешивания | 0,10 ± 0,20 |
| ρ(Λ̂, difficulty) | 0,99 |
| AUC оракула: истинная Λ / Λ, переставленная между темами | 0,6307 / 0,6301 (Δ ≈ 0,0005) |

**Вывод:** контроль в таком виде **нечувствителен** — данные почти не содержат информации о Λ (A насыщает состояние; замер, по коду решателя, видит импульс собственного взаимодействия). Использовать как «подтверждение специфичности» нельзя. Можно показать как приложение с честным пояснением.

### 4.2 Э1б — параметры, при которых забывание наблюдаемо

Параметры выбраны **по оракулу, без обучения**, по порогу ΔAUC (истинная − переставленная Λ) > 0,01: A: диагональ U[0,3; 0,6], внедиагональ 0,05, **β ∈ [2; 3,5]** (достигнуто ΔAUC = 0,018). Сетка кандидатов — в `E1b.selection_grid`.

| (5 сидов) | оригинал | C1: перемешано |
|---|---|---|
| val AUC | 0,654 ± 0,011 | 0,644 ± 0,011 |
| ρ(Λ̂, Λ_true), сырая | 0,45 ± 0,20 | 0,38 ± 0,21 |
| **частная ρ(Λ̂, Λ_true \| difficulty)** | **0,40 ± 0,10** | **0,03 ± 0,11** |
| ρ(Λ̂, difficulty) | 0,98 | 0,99 |

Сырую ρ показывать нельзя: в синтетике Λ_true механически связана с трудностью (ρ = 0,38 в данных), и перемешанный вариант даёт те же 0,38. Корректная метрика — частная корреляция. Разница оригинал − перемешанный положительна в каждом из 5 сидов (+0,37 в среднем). Λ̂ сильно сжата (0,044–0,073 при истинных 0,01–0,2), а ρ(Λ̂, difficulty) остаётся 0,98.

**C2 (BKT), Э1б:**

| параметр BKT | ρ с Λ_true | ρ с difficulty |
|---|---|---|
| prior | −0,27 ± 0,28 | −0,94 |
| learn | −0,59 ± 0,15 | −0,85 |
| slip | 0,29 ± 0,06 (в 2 сидах из 5 не определена) | 0,35 |
| guess | 0,14 ± 0,18 | −0,50 |

BKT истинную Λ не воспроизводит (знак у learn отрицательный, остальное не значимо отлично от нуля) и сильно привязан к трудности. В исходном Э1 guess константен (упёрся в границу), ρ не определена.

**Как читать:** без перемешивания Λ восстанавливается (частная ρ 0,40), после перемешивания — нет (0,03), BKT не воспроизводит. То есть протокол контролей «специфичен» **там, где забывание действительно присутствует**.

### 6.1 В статью (основной текст, абзац в разделе про реальные данные)

> Чтобы проверить, отражает ли оценка Λ забывание, мы выполнили три дополнительных расчёта тем же оценщиком. (i) Замена Λ единственным общим скаляром не меняет AUC (0,6553 в обоих случаях), тогда как трудность темы остаётся в параметре δ (ρ = 0,945). (ii) Если ответы на реальном расписании Junyi смоделированы с одинаковой Λ у всех тем, оценка Λ̂ тем не менее коррелирует с долей ошибок (ρ = 0,72 ± 0,04), а её диапазон (0,030–0,085) практически совпадает с оценённым по реальным данным (0,031–0,085); при Λ, независимой от трудности, ρ = 0,69 ± 0,08. ## 7. Слабые места и отступления от задания (сказать самим)

1. **δ и β — на уровне темы, не упражнения** (`n_items = K`). Из-за этого шаг 3 Э3 вырожден, а «среднее δ по заданиям темы» равно δ_темы. Рецензент мог этого не заметить, но может заметить.
2. **Ранг 25, а не K = 39.** В задании `rank = K`; в конвейере статьи (`lambda_seed_repro_sweep.py`) используется 25 — взят он, чтобы совпасть с основными результатами. Это подтверждено побитовым совпадением с `Lambda_seed*`.
3. **Сиды 0–4, а не 42.** 42 — только препроцессинг.
4. **Один фолд**, обучение на 17 500 учеников. В Э2 расписание использовано для всех 25 000, обучение — на тех же 17 500.
5. **Э1б подобран.** Параметры выбраны по чувствительности оракула, крутизна эмиссии β выше реальной (2–3,5 против ≈ 1,4). Это положительный контроль «на удобных параметрах», а не свойство Junyi.
6. **Э2 использует A, α, β, δ из реальной подгонки** → частично наследует их артефакты; Λ_true в сценарии (b) выбрана перестановкой из 2000 так, чтобы ρ с трудностью ≈ 0.
7. **Решатель и момент импульса.** По коду `_rk4_integrate_shared_grid`, импульс взаимодействия действует на интервал перед его собственным замером (вывод из чтения кода, отдельно не проверялся). Это один из возможных механизмов нечувствительности Э1; обсуждение в статье — на ваше усмотрение.
8. **Большой разброс между сидами в Э1б/Э2** (частная ρ от 0,27 до 0,53 в Э1б; интервалы по темам у отдельных сидов захватывают 0). Писать средние ± SD по сидам, а не отдельные значения.
9. **BKT guess** в Э1 константен (упёрся в границу 0,01), ρ не определена; в Э1б slip не определена в 2 сидах из 5.
